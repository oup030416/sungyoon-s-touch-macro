# 성윤 터치매크로

Android 기기에서 사용자가 직접 지정한 터치와 드래그를 반복 실행하는 개인용 입력 보조 앱입니다. 본인과 가족이 각자의 기기에서 반복 입력에 드는 수고를 줄이기 위해 개발하고 있습니다.

이 저장소는 개발 이력을 관리하고 GitHub Releases를 통해 업데이트를 편리하게 전달하기 위해 공개합니다. 공개 여부나 다운로드 가능 여부가 다른 앱·서비스에서의 자동 입력 사용을 허용한다는 의미는 아닙니다.

## 주요 기능

- 화면에서 터치 위치와 드래그의 시작·끝 위치 지정
- 입력 간격, 반복 실행 및 작업 사이의 대기 시간 설정
- 자주 사용하는 좌표와 설정을 프리셋으로 저장
- 여러 작업을 세트로 구성하고 실행 순서와 시간 조건 설정
- 화면 위의 조작 버튼으로 실행·일시정지·종료 제어

작업 대상과 입력 위치는 사용자가 직접 설정합니다. 앱은 설정된 순서와 조건에 따라 입력을 수행합니다.

## 권한과 작동 방식

| 권한 | 사용 목적 |
| --- | --- |
| 접근성 서비스 | 사용자가 설정한 위치에 Android의 제스처 API로 터치·드래그 실행 |
| 다른 앱 위에 표시 | 좌표 편집 도구와 실행 조작 버튼 표시 |
| 인터넷·네트워크 상태 | GitHub 업데이트 확인·다운로드와 사용자가 제출한 피드백 전송 |
| 이 출처의 앱 설치 허용 | 사용자가 내려받은 업데이트 APK의 설치 진행 |

현재 구현은 접근성 서비스로 화면의 텍스트나 UI 구조를 조회하지 않습니다. 좌표, 프리셋, 세트 등의 작업 설정은 기기에 저장합니다.

## 업데이트

[GitHub Releases](https://github.com/oup030416/sungyoon-s-touch-macro/releases)에서 APK와 변경 내용을 확인할 수 있습니다. 앱에서도 최신 Release를 확인하고 업데이트 APK를 내려받을 수 있으며, 설치는 Android의 안내에 따라 사용자가 진행합니다.

## 피드백

피드백 기능을 사용할 경우, 직접 입력한 내용과 앱 버전·버전 코드·작성 시각·전송 구분용 임의의 메시지 ID가 Google Apps Script를 거쳐 개발자의 이메일로 전달됩니다. 전송 완료가 확인된 메시지는 기기의 발송 대기 목록에서 삭제됩니다.

피드백에는 비밀번호, 인증정보 또는 타인의 개인정보를 포함하지 말아 주세요.

## 사용 범위

본인의 기기 또는 사용 권한이 있는 기기에서, 대상 앱·서비스가 허용하는 범위의 반복 입력에 사용해 주세요. 개인·가족용이라는 개발 목적이 대상 서비스의 이용약관이나 관계 법령보다 우선하지는 않습니다. 실행 전에 입력 위치와 반복 조건을 확인해 주세요.
